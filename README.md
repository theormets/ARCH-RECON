# Copper Bell-Hook Reconstruction & 73-Bell Dataset

Static GitHub Pages website for a measured copper bell-hook reconstruction project.

## Contents

- Two Python-generated CAD reconstruction variants.
- 73-record museum/journal bell-loop dataset in CSV and JSON.
- Full and 50 × 50 mm filtered interactive graphs.
- Measured-hook reference at loop width 6.45 mm and height 8.16 mm.
- Downloadable combined CAD package.

## Measurement status

Published major dimensions are preserved as source data. Visible loop dimensions are image-scaled measurements. The filtered graph changes only the displayed analysis window; it does not delete master records.

## GitHub Pages

Publish the repository root with GitHub Pages or use a Pages workflow. The site entry point is `index.html`.
